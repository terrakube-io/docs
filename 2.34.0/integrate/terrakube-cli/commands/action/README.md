# Workspace Action Commands (`terrakube action`)

Manage custom UI actions and contextual operation buttons displayed within the Terrakube web interface.

- **Aliases**: `actions`

- **[action list](list.md)**: List registered UI actions.
- **[action create](create.md)**: Register a new UI action.
- **[action get](get.md)**: Retrieve action details.
- **[action update](update.md)**: Update action properties.
- **[action delete](delete.md)**: Delete a UI action.
