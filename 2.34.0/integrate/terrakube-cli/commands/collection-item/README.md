# Collection Item Commands (`terrakube collection-item`)

Manage key/value variable items defined inside a collection.

- **[collection-item list](list.md)**: List items in a collection.
- **[collection-item create](create.md)**: Add an item to a collection.
- **[collection-item get](get.md)**: Get collection item details.
- **[collection-item update](update.md)**: Update item key or value.
- **[collection-item delete](delete.md)**: Delete an item from a collection.
