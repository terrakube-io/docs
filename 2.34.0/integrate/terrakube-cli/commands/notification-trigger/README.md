# Notification Trigger Commands (`terrakube notification-trigger`)

Define status triggers (`completed`, `failed`, `pendingApproval`, `running`, `cancelled`) that send alerts through a configured notification channel.

- **Aliases**: `nt`, `notification-triggers`, `trigger`, `triggers`

- **[notification-trigger list](list.md)**: List triggers for a notification configuration.
- **[notification-trigger create](create.md)**: Create a new notification trigger.
- **[notification-trigger get](get.md)**: Retrieve trigger details.
- **[notification-trigger update](update.md)**: Update trigger attributes.
- **[notification-trigger delete](delete.md)**: Delete a notification trigger.
