# Webhook Event Commands (`terrakube webhook-event`)

Configure fine-grained webhook event filters, path matchers, and pull request automation settings.

- **Aliases**: `webhook-events`

- **[webhook-event list](list.md)**: List webhook events.
- **[webhook-event create](create.md)**: Add a webhook event rule.
- **[webhook-event get](get.md)**: Retrieve webhook event details.
- **[webhook-event update](update.md)**: Update webhook event rules.
- **[webhook-event delete](delete.md)**: Delete a webhook event rule.
