# `terrakube github-app-token list`

Lists all stored GitHub App tokens.

## Usage

```bash
terrakube github-app-token list [flags]
```

## Flags

| Flag | Short | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `--output` | | String | No | Output format (`json`, `table`, `yaml`, `tsv`). |

## Examples

### List GitHub App tokens
```bash
terrakube github-app-token list --output table
```
