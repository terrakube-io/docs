# SSH Key Commands (`terrakube ssh`)

Manage SSH private keys used for accessing private Git repositories.

- **[ssh list](list.md)**: List SSH keys.
- **[ssh create](create.md)**: Add an SSH key.
- **[ssh get](get.md)**: View SSH key details.
- **[ssh update](update.md)**: Update SSH key settings.
- **[ssh delete](delete.md)**: Delete an SSH key.
