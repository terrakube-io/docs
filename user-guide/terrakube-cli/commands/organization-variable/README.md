# Organization Variable Commands (`terrakube organization-variable`)

Manage organization global environment variables shared across workspaces.

- **[organization-variable list](list.md)**: List global variables.
- **[organization-variable create](create.md)**: Create a global variable.
- **[organization-variable get](get.md)**: View global variable details.
- **[organization-variable update](update.md)**: Update global variable key or value.
- **[organization-variable delete](delete.md)**: Delete a global variable.
