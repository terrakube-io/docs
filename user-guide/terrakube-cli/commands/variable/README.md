# Workspace Variable Commands (`terrakube variable`)

Manage environment (`ENV`) and Terraform (`TERRAFORM`) variables within a workspace.

- **[variable list](list.md)**: List workspace variables.
- **[variable create](create.md)**: Add a variable to a workspace.
- **[variable get](get.md)**: Retrieve variable details.
- **[variable update](update.md)**: Update variable key, value, or category.
- **[variable delete](delete.md)**: Delete a workspace variable.
