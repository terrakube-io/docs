# `terrakube team-token list`

Lists all active team API tokens.

## Usage

```bash
terrakube team-token list [flags]
```

## Flags

| Flag | Short | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `--output` | | String | No | Output format (`json`, `table`, `yaml`, `tsv`). |

## Examples

### List team tokens
```bash
terrakube team-token list --output table
```
