# Module Version Commands (`terrakube module-version`)

Manage private registry module release versions and Git commit/tag references.

- **Aliases**: `module-versions`

- **[module-version list](list.md)**: List versions for a private module.
- **[module-version create](create.md)**: Publish a new module version.
- **[module-version get](get.md)**: Retrieve module version details.
- **[module-version update](update.md)**: Update version references.
- **[module-version delete](delete.md)**: Delete a module version.
