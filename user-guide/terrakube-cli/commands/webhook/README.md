# Workspace Webhook Commands (`terrakube webhook`)

Configure workspace VCS webhooks for automatic job execution and template triggering.

- **Aliases**: `webhooks`

- **[webhook list](list.md)**: List webhooks configured for a workspace.
- **[webhook create](create.md)**: Create a new workspace webhook.
- **[webhook get](get.md)**: Retrieve webhook details.
- **[webhook update](update.md)**: Update webhook properties.
- **[webhook delete](delete.md)**: Delete a webhook.
