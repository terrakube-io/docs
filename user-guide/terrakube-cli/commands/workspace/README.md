# Workspace Commands (`terrakube workspace`)

Manage workspaces within an organization.

- **[workspace list](list.md)**: List workspaces.
- **[workspace create](create.md)**: Create a workspace.
- **[workspace get](get.md)**: View workspace details.
- **[workspace update](update.md)**: Update workspace settings or soft-delete workspace.
- **[workspace delete](delete.md)**: Delete a workspace.
