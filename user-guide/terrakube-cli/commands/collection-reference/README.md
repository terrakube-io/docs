# Collection Reference Commands (`terrakube collection-reference`)

Link collections to workspaces.

- **[collection-reference list](list.md)**: List references linking collections to workspaces.
- **[collection-reference create](create.md)**: Link a collection to a target workspace.
- **[collection-reference get](get.md)**: Get reference details.
- **[collection-reference delete](delete.md)**: Unlink a collection from a workspace.
