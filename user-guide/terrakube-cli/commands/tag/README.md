# Organization Tag Commands (`terrakube tag`)

Create and manage organization-level tags used to categorize and organize workspaces.

- **Aliases**: `tags`

- **[tag list](list.md)**: List organization tags.
- **[tag create](create.md)**: Create a new tag.
- **[tag get](get.md)**: Retrieve tag details.
- **[tag update](update.md)**: Rename a tag.
- **[tag delete](delete.md)**: Delete a tag.
