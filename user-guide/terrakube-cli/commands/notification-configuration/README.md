# Notification Configuration Commands (`terrakube notification-configuration`)

Manage Slack, Microsoft Teams, and custom Webhook notification integrations at either the organization or workspace level.

- **Aliases**: `nc`, `notification-configurations`, `notification`, `notifications`

- **[notification-configuration list](list.md)**: List notification configurations.
- **[notification-configuration create](create.md)**: Create a new notification configuration.
- **[notification-configuration get](get.md)**: Retrieve notification configuration details.
- **[notification-configuration update](update.md)**: Update an existing notification configuration.
- **[notification-configuration delete](delete.md)**: Delete a notification configuration.
