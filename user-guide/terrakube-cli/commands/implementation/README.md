# Provider Implementation Commands (`terrakube implementation`)

Manage platform binary builds, SHA256 checksums, and PGP signature armor for private providers.

- **[implementation list](list.md)**: List architecture implementations.
- **[implementation create](create.md)**: Register a platform build (OS/arch).
- **[implementation get](get.md)**: Get implementation details.
- **[implementation update](update.md)**: Update implementation parameters.
- **[implementation delete](delete.md)**: Delete an implementation entry.
