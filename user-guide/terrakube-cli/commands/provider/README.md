# Provider Commands (`terrakube provider`)

Manage private registry providers in an organization.

- **[provider list](list.md)**: List providers.
- **[provider create](create.md)**: Register a new private registry provider.
- **[provider get](get.md)**: Retrieve provider details.
- **[provider update](update.md)**: Update provider description.
- **[provider delete](delete.md)**: Delete a provider.
