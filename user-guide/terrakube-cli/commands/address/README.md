# Workspace Address Commands (`terrakube address`)

Manage Terraform/OpenTofu state resource address bindings within job executions.

- **Aliases**: `addresses`

- **[address list](list.md)**: List resource addresses for a job.
- **[address create](create.md)**: Add a resource address.
- **[address get](get.md)**: Retrieve address details.
- **[address update](update.md)**: Update address properties.
- **[address delete](delete.md)**: Delete an address.
