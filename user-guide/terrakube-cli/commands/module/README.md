# Organization Module Commands (`terrakube module`)

Manage private registry Terraform modules.

- **[module list](list.md)**: List organization modules.
- **[module create](create.md)**: Register a module.
- **[module get](get.md)**: Get module details.
- **[module update](update.md)**: Update module properties.
- **[module delete](delete.md)**: Delete a module.
