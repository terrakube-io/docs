# Organization Agent Commands (`terrakube agent`)

Manage self-hosted execution agents within an organization.

- **[agent list](list.md)**: List registered agents.
- **[agent create](create.md)**: Register an agent.
- **[agent get](get.md)**: View agent configuration.
- **[agent update](update.md)**: Update agent settings or endpoint URL.
- **[agent delete](delete.md)**: Unregister an agent.
