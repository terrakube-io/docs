# Project Access Commands (`terrakube project-access`)

Manage team permissions on projects.

- **[project-access list](list.md)**: List project access rules.
- **[project-access create](create.md)**: Grant team permissions on a project.
- **[project-access get](get.md)**: View project access rule details.
- **[project-access update](update.md)**: Update team permissions on a project.
- **[project-access delete](delete.md)**: Remove team permissions from a project.
