# Workspace Tag Commands (`terrakube workspace-tag`)

Associate tags with workspaces.

- **[workspace-tag list](list.md)**: List workspace tags.
- **[workspace-tag create](create.md)**: Associate a tag with a workspace.
- **[workspace-tag get](get.md)**: Retrieve workspace tag details.
- **[workspace-tag delete](delete.md)**: Remove tag association from a workspace.
