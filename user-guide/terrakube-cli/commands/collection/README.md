# Collection Commands (`terrakube collection`)

Manage reusable collections of environment variables and Terraform variables.

- **[collection list](list.md)**: List collections.
- **[collection create](create.md)**: Create a collection.
- **[collection get](get.md)**: Get collection details.
- **[collection update](update.md)**: Update collection attributes.
- **[collection delete](delete.md)**: Delete a collection.
