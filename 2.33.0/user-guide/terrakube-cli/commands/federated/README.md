# Federated Identity Commands (`terrakube federated`)

Manage OIDC federated identity credentials.

- **[federated list](list.md)**: List federated credentials.
- **[federated create](create.md)**: Create a federated identity credential.
- **[federated get](get.md)**: View federated credential details.
- **[federated update](update.md)**: Update federated identity settings.
- **[federated delete](delete.md)**: Delete a federated credential.
