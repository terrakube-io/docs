# Federated Claim Commands (`terrakube federated-claim`)

Manage identity claims defined on federated identity credentials.

- **[federated-claim list](list.md)**: List claims.
- **[federated-claim create](create.md)**: Add a claim to a federated credential.
- **[federated-claim get](get.md)**: View claim details.
- **[federated-claim update](update.md)**: Update claim properties.
- **[federated-claim delete](delete.md)**: Delete a claim.
