# Job History Commands (`terrakube history`)

View and manage execution history records and state snapshots across workspaces.

- **Aliases**: `histories`

- **[history list](list.md)**: List workspace history records.
- **[history create](create.md)**: Create a history snapshot record.
- **[history get](get.md)**: Retrieve history record details.
- **[history update](update.md)**: Update history record attributes.
- **[history delete](delete.md)**: Delete a history record.
