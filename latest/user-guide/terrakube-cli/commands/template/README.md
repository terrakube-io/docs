# Template Commands (`terrakube template`)

Manage workflow execution templates defined in Terrakube Command Language (TCL) YAML.

- **[template list](list.md)**: List templates.
- **[template create](create.md)**: Create a workflow template.
- **[template get](get.md)**: Get template details.
- **[template update](update.md)**: Update template TCL content.
- **[template delete](delete.md)**: Delete a template.
