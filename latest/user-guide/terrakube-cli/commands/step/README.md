# Job Step Commands (`terrakube step`)

Inspect and manage individual execution steps within a Terrakube job lifecycle.

- **Aliases**: `steps`

- **[step list](list.md)**: List execution steps for a job.
- **[step get](get.md)**: Retrieve step details and logs.
- **[step update](update.md)**: Update step status or output.
- **[step delete](delete.md)**: Delete a job step.
