# GitHub App Token Commands (`terrakube github-app-token`)

Manage GitHub App installation tokens for fine-grained VCS repository access.

- **Aliases**: `github-app-tokens`

- **[github-app-token list](list.md)**: List GitHub App tokens.
- **[github-app-token create](create.md)**: Store a new GitHub App token.
- **[github-app-token get](get.md)**: Retrieve token details.
- **[github-app-token update](update.md)**: Update token properties.
- **[github-app-token delete](delete.md)**: Delete a GitHub App token.
