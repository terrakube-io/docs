# Job Commands (`terrakube job`)

Trigger, inspect, and manage Terraform and OpenTofu execution jobs (`plan`, `apply`, `destroy`) across workspace workflows.

- **Aliases**: `jobs`

- **[job list](list.md)**: List jobs within an organization or workspace.
- **[job create](create.md)**: Trigger a new execution job.
- **[job get](get.md)**: Retrieve job details and status.
- **[job update](update.md)**: Update job properties or status.
- **[job delete](delete.md)**: Delete or cancel a job.
