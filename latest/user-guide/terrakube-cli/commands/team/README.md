# Team Commands (`terrakube team`)

Manage teams and organization role permissions.

- **[team list](list.md)**: List teams within an organization.
- **[team create](create.md)**: Create a team with fine-grained permission flags.
- **[team get](get.md)**: View team configuration.
- **[team update](update.md)**: Update team permissions.
- **[team delete](delete.md)**: Delete a team.
