# Workspace Schedule Commands (`terrakube workspace-schedule`)

Configure recurring cron expressions to automatically run templates (e.g. drift detection, periodic plans, or schedule applies) on workspaces.

- **Aliases**: `workspace-schedules`

- **[workspace-schedule list](list.md)**: List schedules for a workspace.
- **[workspace-schedule create](create.md)**: Create a new cron schedule.
- **[workspace-schedule get](get.md)**: Retrieve schedule details.
- **[workspace-schedule update](update.md)**: Update cron expression or template.
- **[workspace-schedule delete](delete.md)**: Delete a schedule.
