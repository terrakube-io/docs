# Team Token Commands (`terrakube team-token`)

Generate, inspect, and revoke API access tokens scoped to specific RBAC teams and groups.

- **Aliases**: `team-tokens`

- **[team-token list](list.md)**: List existing team tokens.
- **[team-token create](create.md)**: Generate a new team token.
- **[team-token delete](delete.md)**: Revoke a team token.
